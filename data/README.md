# Private Runtime Data

This directory is intentionally excluded from version control except for this notice.

- `cv/`: source CV files provided by the user.
- `profiles/`: extracted CV text and structured candidate profile.
- `sessions/`: persistent browser profiles and cookies. Protect as credentials.
- `logs/`: JSONL WebABI audit records and runtime logs.
- `applications/`: discovered jobs, drafts, approval records, and daily updates.

The install script creates these directories with user-only permissions.
